# AI-assisted development policy

AI tools may assist with planning, code, tests, documentation, and review. The human team remains responsible for every submitted artifact.

## Required controls

1. Do not provide AI tools with credentials, production data, personal identifiers, receipts, private organizer messages, or proprietary third-party source.
2. Review generated code for correctness, security, privacy, accessibility, licensing, and fit with the source documents.
3. Run repository quality gates and retain concrete evidence for material changes.
4. Verify third-party license and copyright status before adding assets or copied material.
5. Record material AI assistance and human validation in the pull request.
6. Never represent generated placeholders, unverified claims, or roadmap behavior as implemented.

## Human review record

Each pull request should identify the responsible contributor, affected slice, tests run, privacy impact, and any AI-assisted areas. AI attribution trailers are not added to commits. The team must be able to explain and maintain all submitted code during judging.
